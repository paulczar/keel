# Skills

Reusable procedures for AI agents, loaded on-demand.

Skills are self-contained instructions that agents load lazily via native tooling (e.g., opencode's `skill()` tool). Each skill covers one procedure — syncing configs, managing knowledge, auditing a codebase.

See a skill below for details, or use the search to find specific topics.
